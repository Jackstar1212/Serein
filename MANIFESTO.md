# Serein Manifesto

> *The editor should disappear. Your thoughts remain.*

---

## We Believe

Writing deserves silence.

Software should support thought, not interrupt it.

The best editor is the one you forget you're using.

## Our Principles

**Less is more.** Every feature must justify its existence. The default state is empty — a blank page, waiting for words. Nothing else.

**Content first.** The document is always the primary focus. Toolbars, sidebars, panels, popups — all secondary. All optional. All dismissible.

**Everything optional. Nothing imposed.** Cloud sync, collaboration, grammarly, knowledge graphs — these are choices users make, not defaults we enforce. Plugins are opt-in. Core is minimal.

**Platform-native, not platform-uniform.** Windows feels like Windows. macOS feels like macOS. Linux feels like Linux. We don't sacrifice platform consistency for visual uniformity.

**Modular by design.** The editor is a platform. Plugins provide capabilities — official ones bundled, third-party ones optional. Remove any plugin — the editor still works.

**User freedom above all.** Users decide what to install. Users control their data. Users own their writing environment.

**Privacy by default.** No telemetry, no crash reports, no analytics, no accounts. Your documents, drafts, settings, and logs never leave your machine. Everything stays local.

## We Reject

- Welcome screens that delay the first keystroke
- Anything that interrupts the flow of thought
- Mandatory accounts, logins, or registrations
- Feature creep disguised as "innovation"
- Bloated interfaces that compete with content for attention
- Vendor lock-in through proprietary formats
- Telemetry, analytics, and crash-reporting that phone home
- System trays and background processes that overstay their welcome

## The Test

Before adding anything, we ask:

1. Can it be removed without breaking the editor?
2. Will a user need it the first time they open the app?
3. Does it make the editor more visible, or less?
4. Does it serve the writer, or the platform?

If the answers aren't clear, the feature doesn't belong.

---

*This manifesto is the constitution of Serein. Every decision — technical, design, or product — is measured against it. If something contradicts these words, we don't do it.*
