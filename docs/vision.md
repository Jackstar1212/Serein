# Vision — Serein Product Vision

> **Serein**：法语中"黄昏后的细雨"。不是暴雨，不是阵雨，就是润物细无声。

## 产品愿景

我们正在构建一款 **Markdown 优先的模块化文档编辑器**。

它的内核围绕统一的 **Document Model** 设计（Markdown 只是默认序列化格式，不是编辑器的全部身份）--这赋予它格式无关的可扩展性。但**产品始终是一个编辑器**：克制、专注、可扩展，而非一个包罗万象的"平台"。

> **定位原则**：内核按可扩展方式设计（具备平台级内核的特质），产品按编辑器方式交付。二者不矛盾--正如 VS Code 表面是"代码编辑器"、内核却是扩展平台。"平台 / 生态 / 工作区"等词不进产品定位：它们会诱导范围膨胀，违背 Less is More。内核的每一项抽象仍须通过 MANIFESTO 测试（能移除？用户现在需要？），**"可扩展内核"不是预建平台能力的通行证**。

## 为什么叫 Serein？

Serein 不是在描述编辑器，而是在描述**用户使用编辑器时的心境**。

黄昏雨歇，空气清冽，没有人打扰，可以静静地写点东西。这个画面和你的微信名"向晚初霁"几乎是一回事。编辑器不应该成为主角——它应该像黄昏的细雨一样，安静地存在，却不打扰任何人的思考。

## 我想创造的东西

一个编辑器，用户打开它后：

```
看到的是内容

不是：
菜单、侧栏、AI、图谱、工作区、插件市场
```

用户在 Serein 里的体验应该是：

> "今天写得很顺。"

而不是：

> "这个编辑器好多功能。"

## 设计美学

Serein 的视觉设计追求：**干净、整洁、漂亮、优雅、美观、好用、易上手、轻量、统一**。

- **干净**：没有多余的线条、装饰性元素和视觉噪音。UI 只为服务内容而存在。
- **整洁**：像素级对齐，间距遵循 4px 栅格，层级分明。
- **漂亮**：颜色经过推敲，圆角温柔克制（6-8px 基准），阴影只为表达层级。
- **优雅**：动效克制——hover 过渡 150ms，面板展开 250ms。用户感到流畅，但注意不到动画本身。
- **美观**：每一个像素都经过设计，包括用户看不到的那些。
- **好用**：光标放在哪里，就知道可以做什么。不需要说明书。
- **易上手**：打开就是空白页。输入 `#` 就是标题。零学习曲线。
- **轻量**：安装包尽可能小，启动速度快，内存友好。

> 具体的设计规范、颜色 Token、圆角系统、动效体系，见 [design-language.md](design-language.md)。

## 核心差异化

### 1. 四视图，一套文档模型

不是维护四套编辑器。WYSIWYG / Source / Split / Reading 都是观察同一份 Document Model 的不同方式。切换视图只是换了副眼镜，文档本体始终唯一。

### 2. 模块化不只是口号

每一个模块都可以卸载。删除 Mermaid 模块 → 编辑器照常运行。删除 LaTeX 模块 → 编辑器照常运行。删除所有插件 → 编辑器照常运行。

### 3. 平台原生，不是平台统一

Windows 用户用 Fluent，Mac 用户用 HIG，Linux 用户用 GTK。不为了视觉统一牺牲任何平台的用户体验。

### 4. 纯粹的编辑阅读器，不碰 AI

Serein 是纯粹的编辑器与阅读器，**不内置任何 AI 功能**。需要 AI 的用户自行安装第三方 AI 插件——AI 属于社区生态，不污染核心。Serein 永不主动弹 AI 建议、永不把文档内容发给任何 AI 服务。

### 5. 一体化设计：程序主题与 Markdown 主题联动

Serein 只有一种主题——一个 CSS 文件控制全部（外壳 + 内容 + token + 动画）。不再分"程序主题"和"Markdown 主题"，外壳和内容在同一个文件里天然一体，不会出现"米黄色窗口里嵌着白底文档"的割裂感。详见 [design-language.md](design-language.md)。

## 目标用户画像

**主要用户**：技术写作者、科研人员、论文作者、重度 Markdown 用户。

这类用户的痛点是：
- Typora 的 LaTeX 受限于 KaTeX，很多宏包用不了
- Obsidian 的 Vault 概念对单文件编辑太重
- VS Code 的所见即所得体验不够好
- 现有编辑器缺乏统一的"可执行块"（Mermaid / LaTeX / TikZ / PlantUML）生命周期

## 成功标准

Serein v1.0 成功的标准：

1. 用户打开 `.md` 文件后 1 秒内可以开始编辑
2. 支持 GFM、Mermaid、LaTeX（KaTeX + 可选的 xelatex 管道）
3. 四视图无缝切换（WYSIWYG / Source / Split / Reading），光标位置不丢失
4. 删除任意官方模块不影响编辑器核心功能
5. 第三方可以通过 Plugin API 开发扩展
6. Windows 上有 Fluent 风格，macOS 上有 HIG 风格
7. 安装包 < 15MB

## 不做的事情

- ❌ 不做 AI（Serein 不碰 AI，需要 AI 装第三方插件）
- ❌ 不做知识管理（不是 Obsidian）
- ❌ 不做云同步（可以作为插件）
- ❌ 不做账号系统
- ❌ 不做社区市场（至少在 v1.0 之前不做）
- ❌ 不做实时协作（v1.0 之后再说）
